# MiroFish

Feasibility analysis and financial model for an automated fresh-meal vending machine
("Rice Bowl Machine") at a **₹129 per bowl** price point, for the Indian market.

> **Verdict in one line:** the bowl economics work (₹41.57 food cost, 50% contribution
> margin), the machine economics do not — it needs ~31 meals/day to break even and
> India's largest vending operator publicly does ~3. The idea can be a unicorn, but as a
> **captive-density food brand that uses machines**, not as a vending machine company.

## Financial model

Reproducible, standard-library-only Python. Every assumption is a named constant at the
top of the file — change one number and re-run.

```bash
python3 model/financial_model.py
```

Outputs land in `model/outputs/` as CSV:

| File | Contents |
|---|---|
| `meal_cost_build.csv` | Bottom-up cost of one 400 g bowl |
| `contribution_stack.csv` | Price → contribution margin waterfall |
| `breakeven_by_site.csv` | Break-even meals/day for each of 7 site types |
| `per_machine_pnl.csv` | Full P&L per machine at assumed throughput |
| `volume_reality.csv` | Gap vs. the Daalchini public benchmark |
| `max_supportable_capex.csv` | **The key table** — max buildable machine cost at each throughput |
| `scale_path.csv` | Machines and capital required for ₹10 Cr / ₹250 Cr / ₹1,000 Cr |
| `scenarios.csv` | Bear / base / bull at 500 machines |
| `hopper_capacity.csv` | Why one rice hopper cannot serve 500 meals/day |
| `kill_criteria.csv` | The pre-committed stop conditions |

## Key numbers

| Metric | Value |
|---|---|
| Price | ₹129 / bowl |
| Food + packaging cost | ₹41.57 (32% of price) |
| Contribution per bowl | ₹64.50 (50%) |
| Break-even, captive office | ~31 meals/day |
| Break-even, paid kiosk | ~59 meals/day |
| Daalchini benchmark (FY22) | ₹387 / machine / day ≈ **3 meals/day** at ₹129 terms |
| Max supportable machine cost, 50 meals/day | ₹10 L (captive office) · ₹1 L (paid kiosk) |
| Machine cost target at 100 units | ₹13.3 L |
| Machines for ₹1,000 Cr revenue @ 55 meals/day | ~4,910, requiring ~₹540 Cr of machine capital |

## Notes and caveats

- **The repository was empty at the start of this analysis** (a one-line README). There
  was no existing code or documentation to build on. These documents are the founding
  artefact.
- All market figures are sourced in the appendix of `docs/01-unicorn-analysis.md`.
- All financial figures are generated by the model, not estimated by hand. Where an
  assumption is uncertain it is labelled as such in the text.
- Rent, electricity, packaging, and catering price benchmarks are for **Delhi NCR /
  Haryana, 2026**. Re-base them before using this for another city.
- The model is a planning tool, not a forecast. Its purpose is to tell you **which
  number has to be true**, and how to find out cheaply.
